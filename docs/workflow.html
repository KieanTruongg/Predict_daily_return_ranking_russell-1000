📊 Phase 1: Data Pipeline (Tuần 1-2)

Python yfinance pandas

Xây dựng luồng thu thập và làm sạch dữ liệu thị trường cho rổ chỉ số Russell 1000.

  • Thu thập dữ liệu: Tải danh sách ticker của Russell 1000. Sử dụng Yahoo Finance để tải dữ liệu OHLCV (Open, High, Low, Close, Volume) trong ít nhất 10 năm qua.
  • Phân chia tập dữ liệu:
    ✅ In-sample: Dữ liệu trước 2024-01-01 (dành cho Training & Validation)
    ✅ Out-of-sample: Dữ liệu từ 2024-01-01 trở đi (dành cho Testing/Paper Trading)
  • Xử lý dữ liệu: Xử lý missing data (NaN), điều chỉnh giá (Adjusted Close) do stock splits (chia tách cổ phiếu) và corporate actions (cổ tức).
  • Lưu trữ: Xuất dữ liệu đã làm sạch ra định dạng CSV hoặc Parquet để đọc ghi nhanh gọn.
pip install yfinance pandas numpy

🧮 Phase 2: Feature Store (Tuần 2-3)

pandas numpy ta

Khai phá và xây dựng ma trận đặc trưng (Feature Matrix). Cần tạo ít nhất 50+ features phân loại theo các nhóm:

  • Price-based: Tỷ suất sinh lời (Returns) các khung 1d, 5d, 20d, 60d; Tỷ lệ giá trị so với quá khứ.
  • Moving Averages: Các đường SMA (Simple Moving Average), EMA (Exponential) và tín hiệu giao cắt (crossovers).
  • Technical Indicators: Chỉ báo RSI, MACD, Bollinger Bands, ATR (Average True Range).
  • Volume-based: Volume ratio, OBV (On-Balance Volume), VWAP deviation.
  • Volatility: Biến động thực tế (Realized volatility), Volatility ratio, Max Drawdown.
  • Cross-sectional: Xếp hạng (Rank) của cổ phiếu trong cùng một Sector/Industry, Sức mạnh tương đối (Relative Strength).

Kết quả: Một DataFrame khổng lồ chứa dữ liệu chuỗi thời gian của tất cả các tickers với các cột features sẵn sàng cho bước ML.

pip install ta

🧠 Phase 3: Model Training (Tuần 3-5)

xgboost lightgbm pytorch scikit-learn

Huấn luyện các mô hình học máy với chiến lược Cross-validation đặc biệt cho Time-Series.

1. Mô hình XGBoost (Gradient Boosted Trees)

Sử dụng thư viện xgboost và scikit-learn. Yêu cầu tune các hyperparameters quan trọng như max_depth, learning_rate, subsample.

pip install xgboost

2. Mô hình LambdaMART (Learning-to-Rank)

Sử dụng lightgbm với objective là 'lambdarank'. Trong Quant, bài toán Ranking thường hiệu quả hơn Regression (dự đoán giá trị tuyệt đối) vì ta chỉ quan tâm mã nào tăng mạnh hơn mã nào (Relative Performance).

pip install lightgbm

3. Mô hình LSTM (Deep Learning)

Sử dụng pytorch để nắm bắt tính tuần tự của chuỗi thời gian. Kiến trúc: Input Sequence → Các lớp LSTM → Lớp Dense/Linear → Output dự đoán.

pip install torch

⚠️ Các lưu ý quan trọng:

  • Cross-Validation: Bắt buộc dùng TimeSeriesSplit hoặc Purged K-Fold. TUYỆT ĐỐI KHÔNG dùng k-fold ngẫu nhiên (sẽ bị Data Leakage do nhìn thấy tương lai).
  • Regularization: Áp dụng L1/L2 penalty hoặc Dropout (cho LSTM) để tránh Overfitting - căn bệnh phổ biến nhất trong Quant.
  • Explainability: Dùng thư viện SHAP để phân tích tầm quan trọng của Features. Dùng Optuna để tối ưu siêu tham số.
pip install shap optuna

🤝 Phase 4: Alpha Ensemble (Tuần 5-7)

scikit-learn

Kết hợp 3 mô hình dự đoán (3 tín hiệu Alpha) thành một Meta-Alpha duy nhất nhằm tối ưu Sharpe Ratio.

  • Các phương pháp kết hợp (Ensemble Methods):
    - Equal weight: Trung bình cộng đơn giản.
    - Inverse volatility: Tỷ trọng nghịch đảo với độ biến động (phương sai) của từng Alpha.
    - ML-based (Stacking): Huấn luyện một Meta-model (như Ridge Regression hoặc XGBoost) để học cách kết hợp 3 signals tốt nhất.
  • Đánh giá tương quan: Phân tích Correlation Matrix giữa các Alphas. Yêu cầu các mô hình có độ tương quan thấp để tạo ra lợi ích đa dạng hóa (Diversification benefit).
  • Mục tiêu: Meta Alpha thu được cần đạt Sharpe Ratio giả định > 1.0 trên tập Validation.

📈 Phase 5: Ranking Engine & Backtesting (Tuần 7-8)

pandas numpy matplotlib plotly

Chuyển đổi tín hiệu thành vị thế giao dịch và mô phỏng hiệu suất (Backtest).

  • Chuyển đổi Signal thành Positions: Mỗi ngày, tính Ranking của các cổ phiếu dựa trên Meta-Alpha. Thực hiện Demean (trừ đi trung bình) để tạo ra danh mục Market-Neutral (Long-Short balanced). Mua (Long) top % cao nhất và Bán khống (Short) top % thấp nhất.
  • Đo lường hiệu suất (Metrics):
    - PnL (Profit & Loss) hàng ngày.
    - Cumulative Return (Lợi nhuận tích lũy).
    - Annualized Return (Lợi nhuận hằng năm).
    - Sharpe Ratio (Lợi nhuận tinh chỉnh rủi ro).
    - Max Drawdown.
  • Trực quan hóa: Vẽ biểu đồ đường cong vốn (Equity Curve) và biểu đồ Drawdown theo thời gian.
pip install matplotlib plotly

🌐 Phase 6: REST API & Database (Tuần 8-9)

FastAPI SQLAlchemy SQLite/PostgreSQL

Bọc hệ thống thành các API service để dễ dàng tích hợp.

  • Các Endpoints chính:
    GET /health: Kiểm tra trạng thái server.
    POST /predict: Gửi dữ liệu thị trường mới, nhận về danh sách Ranking cổ phiếu cần mua/bán hôm nay.
    POST /backtest: Chạy lại backtest với cấu hình tham số động.
  • Lưu trữ (Database): Sử dụng SQLAlchemy ORM lưu các kết quả dự đoán (Predictions), Metadata của Models và kết quả Backtest lịch sử vào SQLite (hoặc PostgreSQL).
pip install fastapi uvicorn sqlalchemy

🖥️ Phase 7: Dashboard (Tuần 9-10)

streamlit dash

Xây dựng giao diện Web tương tác trực quan hóa toàn bộ dự án.

  • Các trang (Pages) cần có:
    - Overview: Tóm tắt hiệu suất chiến lược tổng thể.
    - Model Performance: Xem chi tiết từng mô hình XGBoost, LambdaMART, LSTM.
    - Backtest Results: Xem lại các metrics, biểu đồ Equity Curve, Drawdown tương tác.
    - Feature Importance: Trực quan hóa giá trị SHAP, những tính năng nào quan trọng nhất cho dự đoán.
pip install streamlit

🕵️ Phase 8: Monitoring & Retraining (Tuần 10+)

evidently

Giám sát mô hình khi đưa ra thực tế để tránh suy giảm hiệu suất.

  • Data Drift: Phát hiện khi phân phối của các biến đầu vào (features) bị lệch chuẩn so với lúc training (Ví dụ: Chế độ thị trường thay đổi từ Bull market sang Bear market).
  • Model Drift: Theo dõi sự suy giảm hiệu suất dự đoán thực tế.
  • Auto-retraining: Thiết lập cơ chế tự động trigger huấn luyện lại mô hình với dữ liệu mới khi độ lệch vượt quá ngưỡng cho phép (Threshold).
pip install evidently
